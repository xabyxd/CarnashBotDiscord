# CarnashBotDiscord
 Official Carnash Discord bot Repo.

Archivos y Directorios
commands/:
Este directorio contiene archivos JavaScript para cada comando. Separa cada comando en su propio archivo para una mejor organización.

events/:
Este directorio contiene archivos JavaScript para cada evento que el bot escuchará (e.g., ready, interactionCreate).

config/:
Este directorio contiene archivos de configuración. Puedes almacenar configuraciones globales del bot en un archivo JSON.

bot.js:
Archivo principal que inicializa el bot y carga comandos y eventos.

package.json y package-lock.json:
Archivos generados por npm que contienen las dependencias y la configuración del proyecto.

README.md:
Archivo opcional para documentar tu proyecto.
